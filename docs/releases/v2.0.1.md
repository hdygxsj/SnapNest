# 轻屿 2.0.1（SnapNest）

本次为 macOS 界面体验与窗口修复更新，所有功能继续免费开源。

## 更新内容

- 修复系统标题栏下方叠加的圆角和描边。主窗口统一使用 macOS 原生边框，收起后的待办胶囊保留独立圆角。
- 突出区域截图主操作，完善按钮悬停、按下、键盘焦点与无障碍标签。
- 最近捕捉增加时间信息；仅在超过三条记录时显示「查看全部」。
- 补充捕捉中的状态、录制暂停/继续和结束保存入口，改善权限与错误提示。
- 改善待办胶囊在刘海旁和外接显示器上的定位。

## 下载与安装

下载 `SnapNest-v2.0.1-macos-universal.zip`，解压后将「轻屿.app」放入「应用程序」。支持 macOS 15 及更新系统，包含 Apple Silicon 和 Intel 两种架构。`SHA256SUMS.txt` 用于校验安装包。

升级前退出旧版拾图或轻屿，再替换应用；已有截图、设置和本地办公数据保留。

安装包使用 ad-hoc 临时签名，未经过 Apple 公证。更新后可能需要重新授权屏幕录制、提醒事项或辅助功能，应用不会自行修改系统权限。

## 验证

18 组核心测试及启动器、快捷键、外观、窗口、待办、办公、画质、编辑器和截图流程检查通过。通用安装包的双架构、临时签名、ZIP 完整性与 SHA-256 校验通过。
