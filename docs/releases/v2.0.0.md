# 轻屿 2.0.0（SnapNest）

轻屿 2.0 全部源码以 MIT 协议开源，所有功能免费，不含 Pro 内购。

## 2.0 更新
- 统一可移动、可缩放的工作窗口，记住位置，支持浅色、深色和跟随系统。
- 快捷启动支持搜索、收藏卡片和每个应用独立全局快捷键。
- 接入系统提醒事项，支持选中文字添加待办；iCloud 列表可由系统同步到 iPhone。
- 图文教程、文件暂存篮、工作现场和截图对比全部开放。
- 高清 PNG 保留 Retina 原始像素，高清 GIF 最高 1920 像素 / 20 fps；可选择标准画质。
- 保留截图标注、窗口截图、取色、OCR、钉图、再次截取、长截图、录屏和录制暂停。
- 恢复 GitHub 公开版本检查，安装包沿用 SnapNest 文件名以兼容旧版更新器。

## 下载与安装
下载附件 SnapNest-v2.0.0-macos-universal.zip，解压后将「轻屿.app」放入「应用程序」。
需要 macOS 15 或更新版本，支持 Apple Silicon 与 Intel。
升级前退出旧版拾图/轻屿，再替换应用；已有截图文件和本地数据保留。
本包为 ad-hoc 临时签名，未经过 Apple 公证。macOS 可能提示未验证开发者；更新后屏幕录制等权限可能需要重新授权。应用不会自动修改系统安全设置。

## 快速上手
- 截图：⌘⇧X，拖动框选；双击截图退出并复制，到目标应用按 ⌘V。
- 录屏/GIF：框选后选择录屏或 GIF，在原区域继续录制；⌘⇧X 或停止按钮结束。
- 长截图：框选滚动正文，选择长截图，缓慢向下滚动，每次不超过半屏。
- 快捷启动：⌘⇧空格，搜索应用；点击应用右侧键盘设置独立快捷键。
- 待办：先连接系统提醒事项列表，再选中文字按 ⌘⇧T；读取选区需要辅助功能授权。

## 验证与限制
核心、画质和办公功能检查通过，安装包包含 arm64/x86_64 两种架构。
GIF 受 256 色格式限制，单次最多 30 秒；长截图需手动滚动。iCloud 同步由系统负责。
