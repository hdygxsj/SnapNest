# SnapNest 1.3 implementation plan

Goal: ship numbered annotations, repeat capture, and pausable recording to GitHub and Gitee with all previously completed productivity features.

Architecture: keep the existing AppKit editor and ScreenCaptureKit capture path. Numbering lives in undoable editor snapshots. Repeat capture stores display identity and local coordinates, validating them against the connected display. Recording pauses finalize temporary MP4 segments; resume starts another segment with the same configuration. AVFoundation joins segments without paused time and preserves audio timing. The HUD, main view, and menu expose the same state.

- [x] Add regression checks for numbering, repeat geometry, paused elapsed time, and real media concatenation.
- [x] Add numbered circles with undo/redo and numbering preserved through crop.
- [x] Persist the last successful capture region; expose repeat in main and menu, reject missing displays/out-of-bounds coordinates.
- [x] Implement pause/resume, prevent overlapping transitions, permit stop while paused, apply the GIF cap to active time.
