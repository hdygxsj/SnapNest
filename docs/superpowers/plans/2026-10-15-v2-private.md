# SnapNest 2.0 Implementation Plan

> Execute component tasks with superpowers:subagent-driven-development, then integration and review. No push, public release, or modification of user Reminders in tests.

**Goal:** Private v2.0 with quick launcher, selected-text Reminders capture, task island.
**Architecture:** Isolated launcher model/controller; EventKit task model and panel; selected-text reader/controller; AppDelegate coordinates capture suppression and global shortcuts.
**Tech Stack:** Swift, SwiftUI, AppKit, EventKit, Accessibility, existing SwiftPM build.

- [x] Task 1: `TaskCenter.swift`, `TaskIsland.swift`: explicit authorization, dedicated-list binding, create/edit title+due/complete, source labeling, stale fetch protection and errors, top panel count. Expose `TaskCenterController.showComposer(text:)`, `showTasks()`, `setCaptureActive(_:)`, `start()`; keep permission requests user initiated. Add fake-backed checks without system data writes.
- [x] Task 2: `QuickLauncher.swift`, `ShituCore/LauncherSearch.swift`: installed app scan outside main thread, local favorites, keyboard search/open, add file/folder/web controls, errors for missing target. Verify search ordering and URL safety with core tests before implementation.
- [x] Task 3: `SelectedTextCapture.swift`: AX selected text, opt-in mouse-up bubble, explicit paste fallback, permission education, dismiss stale bubble. Wire two additional Carbon shortcuts with unique event IDs, avoid all handlers firing on each key.
- [x] Task 4: `App.swift`, `MenuBarPanel.swift`: wire launcher/tasks, show shortcut availability, suppress floating UI during capture, refresh tasks on wake and activation. Preserve capture shortcut and resident behavior.
- [x] Task 5: Info.plist 2.0.0/build6 and Reminders descriptions; private channel guard in UpdateController; private distribution documentation, original notices retained.
- [x] Task 6: `swift run ShituCoreChecks`, app verification mode, SwiftPM debug and universal release; inspect UI; independent code review; package only into local dist/private/v2.0.0, no uploads.
