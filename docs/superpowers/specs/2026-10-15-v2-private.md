# SnapNest 2.0 private edition

User approved system Reminders integration, launcher, selected-text task capture and top-of-screen task count. Version 2.0.0, local/private development only; no remote pushes or public assets. Previous published MIT versions remain unchanged.

Launcher: searchable installed apps and persistent favorites for applications, folders and web URLs. Command-Shift-Space opens launcher; Escape closes, Return launches the selected result. No shell execution.

Reminders: EventKit full access requested only when user connects. Use one dedicated SnapNest calendar; allow explicit writable-list selection if needed. Do not read or mutate unrelated reminders. Display account/source and explain iCloud requirements, do not label every CalDAV account iCloud. Add editable title and optional due date, complete/uncomplete, reload on store changes, activation and explicit refresh. Permission denial and removed calendar are visible recoverable states. Never create or complete real user reminders during automated tests.

Selection: Command-Shift-T reads focused application's AX selected text before activating app. Optional selection bubble after mouse-up, default off until enabled, skips secure fields and own app. No silent copy simulation or clipboard overwrite. If inaccessible, show empty composer with explicit Paste button. Cancel leaves store untouched.

Island: compact top-center panel below notch/menu bar with unfinished count. Click opens task panel; enabled toggle, multi-display/reconfiguration positioning; hide during capture/recording to avoid contamination. No claim of native iPhone Dynamic Island integration.

Privacy: launcher favorites stay local. Reminders are system-managed and may sync through user's configured account. No custom backend. v2 public GitHub updater disabled; private update channel not yet configured. Preserve original MIT notices for reused v1 code and clearly mark v2 additions private.

Verification: core search/normalization/geometry tests, EventKit repository seam for denial/fetch/stale results/create and complete failure without user data, build arm64/x86_64, UI render/manual smoke where available. Actual iCloud phone sync needs user's authorized devices and cannot be proven by a mock.
