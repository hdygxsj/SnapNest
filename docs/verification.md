# 验证范围

开发验证环境：macOS 26 / Apple Silicon / Swift 6。最低部署版本为 macOS 15，其他系统版本仍需实机验证。

## 自动化检查

```sh
swift run ShituCoreChecks
swift run Shitu --verify-editor
swift build -c release
```

- 核心测试 12 组：显示器坐标与裁剪、重叠匹配、重复帧、噪声处理、实际 CGImage 多帧拼接、编辑历史、GIF 导出、TCC 拒绝状态、浮动工具条定位和登录项控制器状态。
- GIF 测试使用合成 MP4，检查输出帧数、尺寸、播放间隔和循环参数。
- 编辑器检查标注像素位置和颜色、马赛克、裁剪位置与撤销/重做。
- 工具条支持离屏渲染检查；示例见 [toolbar-preview.png](toolbar-preview.png)。

这些检查不等同于真实桌面和系统音频的端到端验收。登录项测试覆盖控制器的状态处理，不会重启或退出登录，也不会修改测试机器的登录项。

## 人工验收

1. 打开打包后的拾图，完成屏幕录制授权。
2. ⌘⇧X 框选，检查原位截图和紧凑工具条。依次试用标注、马赛克、裁剪、撤销、复制和保存。
3. 框选后点击“录屏”，确认不重新框选，录制原区域；检查 MP4 播放和系统声音。
4. 框选滚动正文后点击“长截图”，缓慢下滚，检查拼接边界并保存。
5. 框选后点击“GIF”，检查提前停止、30 秒自动停止和循环播放。
6. 在历史中重新编辑 PNG，确认保存为新文件、原文件保留。
7. 覆盖副显示器、Retina、靠近屏幕边缘的选区、全屏应用和权限拒绝恢复。
8. 开启和关闭登录时自动启动，检查系统登录项状态，并在独立测试环境重新登录验证。

## 已知限制

- 长截图依赖手动纵向滚动；固定导航栏、动态内容、重复图案和过快滚动可能无法对齐。
- 视频不包含麦克风；GIF 为无声、10 fps、最长 30 秒、最长边 960 像素。
- 默认本机临时签名，未公证。开发版更新后可能需要重新启用录屏授权。
- 对登录启动的真实注册及重新登录行为，仍需在使用者的系统和签名配置下验收。
