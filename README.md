# 轻屿 2.0 · 私有版

当前分支为本地私有开发版本。**不推送 GitHub/Gitee，不创建公开发行版，不公开安装包。**
v1.x 已公开代码仍保留原 MIT 许可；v2 新增代码未以开源许可发布，见 [LICENSE](LICENSE)。

## 界面

截图、快捷启动、待办、办公与设置共用一个可拖动、可缩放并记住位置的工作窗口，支持跟随 macOS、浅色和深色外观。深浅色统一采用顶部导航，分别使用蓝白与紫灰配色，最近捕捉支持真实缩略图预览。收起后默认隐藏，不常驻屏幕顶部；可在待办页手动开启常驻计数，显示未完成数量（读取不可用时显示 —）。通过导航切换功能；编辑待办在面板内完成。Esc 或关闭按钮收起并保留未保存草稿，应用继续驻留；点击窗口外不会自动收起。截图和录屏期间隐藏。

## 新功能

- 快捷启动：⌘⇧空格，搜索应用，支持拼音/首字母；收藏应用、文件夹和 HTTP(S) 网页。上下键选择、Return 打开、Esc 关闭。每个 App 旁可设置独立全局快捷键，直接启动或切换应用；支持修改、清除、冲突提示和重启恢复。
- 划词待办：选中文字后按 ⌘⇧T。菜单栏「划词设置」可开启选词后浮动按钮，需要辅助功能权限。无法读取时在编辑框点击「粘贴」。
- 系统提醒事项：在「待办与灵动岛」连接系统提醒事项，选择已有 SnapNest 列表或指定账户创建。支持标题、截止日期时间和完成状态。
- 顶部待办条：显示专用列表未完成数量，点击展开；可关闭，截图与录屏期间自动隐藏。
- 原截图快捷键 ⌘⇧X 和截图/录屏/GIF 功能继续保留。

## Pro 高清画质

计划通过 Mac App Store 非消耗型内购以 ¥12 一次性买断；应用展示 StoreKit 返回的实际本地价格。设置中支持购买、恢复购买和高清开关，权益只接受已验证交易，退款后重新检查并取消权益。

标准 PNG 为逻辑尺寸，Pro 保留屏幕原始 Retina 像素；PNG 本身均为无损格式。标准 GIF 最长边 960 像素、10 fps，Pro 最长边 1920 像素、20 fps，不放大小尺寸源；GIF 仍受 256 色限制。取色放大镜始终使用原始像素。每次捕捉开始时确定画质，录制中切换设置不会改变当前录制。

目前完成客户端接入和模拟交易测试，尚未配置真实商品或通过 App Store 沙盒测试。本地临时签名安装包不能作为内购上线证明。上线步骤见 [App Store 配置](docs/app-store-pro-setup.md)。

## Pro 办公工具

在同一面板的「办公」页切换四项工具，沿用 ¥12 一次性买断 Pro，无单独收费。真实购买仍需 App Store 上线准备完成。

- 图文教程：新建教程，导入图片或点击「截图添加」，为步骤标注、写说明、上下排序和替换。导出每步一页的 PDF 或长图 PNG。素材在本机保存独立副本；删除教程或步骤需确认，标注保存后合并进图片。最多 100 步，图片最长边 4096；长图最多 1200×20000，超过限制可导出 PDF。
- 文件暂存篮：拖入或选择文件，勾选后复制或从底部一起拖出。移出只删引用，不移动或删除原文件。使用持久书签，文件不可访问时提示重新添加。已解锁 Pro 时，拖文件到主屏幕顶部中央可展开暂存篮（待真实 Finder 拖放复测）。
- 工作现场：命名并保存一组应用、文件夹和 HTTP(S) 网页；可加入当前运行的应用，一键打开并显示逐项错误。网页和文件夹需手动添加，不读取浏览器标签、不恢复窗口位置或未保存文档。
- 截图对比：选择修改前后图片，左右或滑动对照，按容差显示像素差异，填写验收意见并导出 PNG 报告。差异分析要求原图尺寸一致，最长边按 2048 像素分析。对比素材只保留在本次会话，退出后不保存。

教程、暂存篮和工作现场存放在本机 Application Support/QingyuOffice。没有上传或分享服务；拖到其他应用后由目标应用处理。没有 Pro 时已有资料可查看，创建、修改和导出仍校验权益。

验证入口：`swift run Shitu --verify-office`；隔离样例界面：`swift run Shitu --render-office .build/office-preview`。测试只在临时目录使用模拟权益，不解锁实际用户账号。

## iPhone 同步

创建列表时选 iCloud 账户；Mac 和 iPhone 登录同一个 Apple 账户并开启 iCloud 提醒事项。
手机使用系统「提醒事项」查看或完成。同步由系统负责，并非即时保证；本地或其他账户列表不能保证同步到 iPhone。
无需自建后台，也无需单独安装 SnapNest iPhone App。

## 权限与数据

首次连接时由系统请求提醒事项访问；只有明确选择的 SnapNest 列表会被读取和写入。
辅助功能由用户在系统设置中开启，划词不模拟复制、不覆盖剪贴板，不保存未提交的选择文本。
截图与录屏保存在本机；待办使用系统账户存储和同步；启动器收藏只保存在本机。

## 构建与验证

```sh
swift build
swift run ShituCoreChecks
Tests/LauncherChecks/run.sh
swift run Shitu --verify-v2
bash scripts/build-release.sh
```

安装包只生成在 `dist/private/v2.0.0/`。签名可通过 `SHITU_SIGNING_IDENTITY` 配置；未配置时沿用本机临时签名，未公证，重新构建后可能需要重新授权。
2.0 不再请求公开 GitHub 更新接口；私有更新渠道尚未配置，更新使用本地安装包。
