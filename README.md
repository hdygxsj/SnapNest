# SnapNest 2.0 · 拾图私有版

当前分支为本地私有开发版本。**不推送 GitHub/Gitee，不创建公开发行版，不公开安装包。**
v1.x 已公开代码仍保留原 MIT 许可；v2 新增代码未以开源许可发布，见 [LICENSE](LICENSE)。

## 界面

截图、快捷启动、待办与设置共用一个顶部面板，深浅外观跟随 macOS。收起后默认隐藏，不常驻屏幕顶部；可在待办页手动开启常驻计数，显示未完成数量（读取不可用时显示 —）。面板顶部切换功能；编辑待办在面板内完成。Esc 或点击面板外收起并保留未保存草稿。截图和录屏期间隐藏。

## 新功能

- 快捷启动：⌘⇧空格，搜索应用，支持拼音/首字母；收藏应用、文件夹和 HTTP(S) 网页。上下键选择、Return 打开、Esc 关闭。每个 App 旁可设置独立全局快捷键，直接启动或切换应用；支持修改、清除、冲突提示和重启恢复。
- 划词待办：选中文字后按 ⌘⇧T。菜单栏「划词设置」可开启选词后浮动按钮，需要辅助功能权限。无法读取时在编辑框点击「粘贴」。
- 系统提醒事项：在「待办与灵动岛」连接系统提醒事项，选择已有 SnapNest 列表或指定账户创建。支持标题、截止日期时间和完成状态。
- 顶部待办条：显示专用列表未完成数量，点击展开；可关闭，截图与录屏期间自动隐藏。
- 原截图快捷键 ⌘⇧X 和截图/录屏/GIF 功能继续保留。

## iPhone 同步

创建列表时选 iCloud 账户；Mac 和 iPhone 登录同一个 Apple 账户并开启 iCloud 提醒事项。
手机使用系统「提醒事项」查看或完成。同步由系统负责，并非即时保证；本地或其他账户列表不能保证同步到 iPhone。
无需自建后台，也无需单独安装 SnapNest iPhone App。

## 权限与数据

首次连接时由系统请求提醒事项访问；只有明确选择的 SnapNest 列表会被读取和写入。
辅助功能由用户在系统设置中开启，划词不模拟复制、不覆盖剪贴板，不保存未提交的选择文本。
截图与录屏保存在本机；待办使用系统账户存储和同步；启动器收藏只保存在本机。

## 构建与验证

```sh
swift build
swift run ShituCoreChecks
Tests/LauncherChecks/run.sh
swift run Shitu --verify-v2
bash scripts/build-release.sh
```

安装包只生成在 `dist/private/v2.0.0/`。签名可通过 `SHITU_SIGNING_IDENTITY` 配置；未配置时沿用本机临时签名，未公证，重新构建后可能需要重新授权。
2.0 不再请求公开 GitHub 更新接口；私有更新渠道尚未配置，更新使用本地安装包。
